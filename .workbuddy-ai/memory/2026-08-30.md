# 2026-08-30

## Messages overhaul (pages/messages.html, js/messages.js, css/messages.css)

- **Live refresh bug (root cause found).** In server mode `store.sendMessage()`
  POSTed to `/api/messages` and adopted the returned `version`, but never
  updated `serverCache['clinic_messages']`. The 4s version poll therefore saw
  no change and never re-fetched, so a sender only saw their own message after
  a full page reload. Fixed in `js/store.js`: merge the returned message into
  the cache and `announceChanges([KEYS.messages])`. Also added `store.refresh()`
  calls after the appointment decision and profile save.
- **Auto role groups.** Removed the "Role broadcast" option from the new-chat
  modal. `syncRoleGroups()` now maintains one group per role (`role_admin`,
  `role_doctor`, `role_nurse`, `role_billing`, `role_lab`) in `clinic_groups`,
  with membership rebuilt from `clinic_staff_members` on every load, so any
  active account joins the moment it exists.
- **Chat categories.** Sidebar split into Announcements / Role chats / Group
  chats / Individual chats, each with a minimize chevron. Collapsed state is
  per-user, stored in `meditrack_msg_sections_<user>`.
- **Delete.** Group chats: creator/admin can delete for everyone; any member
  can leave. Any conversation: "Delete chat" hides it on this workstation
  (new collection `clinic_chat_hidden`) and posts a `kind:'system'` notice into
  the thread, e.g. "Abebe deleted the chat on Sunday, Aug 30, 2026 at 8:12 PM".
  A hidden chat reappears if anyone writes again.
- Removed the "To: / Group: / To role:" recipient pill above the composer.

## Server (server.js)

- `clinic_chat_hidden` added to `COLLECTIONS` (all roles may write).
- `handleSendMessage` accepts `kind:'system'` for chat notices.
- `handleRemoveStaff` now also purges that user's hidden-chat records.

## Icons (js/icons.js)

- Added `more` (vertical dots), `minus`, `user-minus`, and the alias
  `archive -> storage` (the "Save to Inventory" menu icon was rendering blank).

## Accent fills for selected states

Pale `--primary-light` / white fills read as "unselected", so selected controls
now use the solid accent with `--primary-contrast` text (same as
`.msg-conv.active`): `.filter-chip.active` (components + appointments),
`.chip.active`, `.notif-filter-chip.active`, `.wb-chip.active`,
`.policy-option.active` (settings calling policy), `.set-nav-item.active`,
`.role-option.selected` (login). Lab flag chips keep their own colours via
higher-specificity rules.
